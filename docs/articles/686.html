「強大的鴨子」

文法重點

  • 現在分詞片語作後位修飾
    ...at an event appointing the characters as anti-vote-buying ambassadors.
    句中的「appointing the characters as anti-vote-buying ambassadors」是由現在分詞開頭的片語，用來修飾前方名詞「event」，相當於形容詞子句「...at an event which/that appointed the characters...」，在多益閱讀測驗中常出現以簡化句子結構。
