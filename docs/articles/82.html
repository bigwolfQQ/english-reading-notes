文法重點

  • 過去分詞片語作後位修飾 (Past Participle as Post-modifier)
    This surpassed the previous record for August rainfall, set in 1931, and was four times the monthly average, it added.
    句中的「set in 1931」是過去分詞片語，用來修飾前面的名詞「the previous record for August rainfall（8月降雨量的先前紀錄）」。其原貌為關代子句「which was set in 1931」，經簡化後直接保留過去分詞片語，能讓商業與新聞英文句子更簡潔流暢。
  • 非限定關係代名詞子句 (Non-defining Relative Clause)
    Guava growers were the second worst affected, losing 201.35 hectares worth NT$16.959 million, followed by papaya farms, which lost 58.23 hectares worth NT$12.604 million.
    句尾的「which lost 58.23 hectares...」是一個由逗點隔開的非限定關係子句，用來補充說明前面的先行詞「papaya farms（木瓜農場）」。在多益閱讀測驗中，常考此類結構來測試考生對代名詞指代與句子結構的理解。
  • 倍數表達法 (Expressing Multiples)
    This surpassed the previous record for August rainfall, set in 1931, and was four times the monthly average, it added.
    英文表達「幾倍」的標準句型為「數字 + times + 名詞/代名詞（如 the average）」。句中的「four times the monthly average」即表示「該月平均雨量的四倍」，這是多益考試中非常實用的數量與數據描述句型。
