文法重點

  • 過去分詞片語作後位修飾語（分詞構句/形容詞用法）
    With the new product — dubbed the Open Agent Safety Platform — Nvidia is offering a way to prevent breaches without curbing AI development.
    句中的「dubbed the Open Agent Safety Platform」是過去分詞片語，用來修飾前面的名詞 the new product（被稱為……）。原本的完整子句可能是「which is dubbed...」，在此省略了「which is」，直接留下過去分詞片語作後位修飾，是多益閱讀測驗中常見的精簡句構。
  • 與過去事實相反的假設語氣（Past Unreal Conditional）
    If cutting-edge labs had been using this technology to evaluate their AI models early on, the Hugging Face attack could have been averted...
    此句使用了與過去事實相反的假設語氣。If 子句中使用過去完成式（had been using），主句則使用「助動詞過去式 + have + 過去分詞」（could have been averted）。用來表達「如果當初……，（過去）本來就可以……」的假設情況。
  • 關代所有格（whose 的變化型 / 介系詞 + 關係代名詞）
    The semiconductor giant, which has been rapidly expanding its product lineup beyond chips, is rolling out two open-source software security tools that can be run on its hardware.
    句中的「which has been rapidly expanding...」是非限定用法的關係子句，用逗號與主句隔開，補充說明前方主詞 The semiconductor giant。關係代名詞「which」代替先行詞作主詞，引導子句描述該半導體巨頭的動態。
  • 現在分詞作後位修飾語
    As the problems proliferated, OpenAI on Friday said that it would pause training of its most capable AI models.
    句首由「As」引導的時間副詞子句中，「the problems proliferated」為主動語態的子句。而在文章其他段落中常可見現在分詞（如 expanding）直接修飾名詞或表達主動連續動作，多益常考分詞的主被動語態區分。
