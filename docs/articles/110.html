文法重點

  • 非限定性關係子句 (Non-restrictive Relative Clause)
    ...a hacking incident at the military-affiliated Chungshan Institute of Science and Technology (CSIST), which said it would establish appropriate response standard operating procedures for its procurement system.
    句中的「which said...」前面帶有逗號，用來補充說明前面的先行詞（中科院），提供額外的資訊，翻譯時可順著語意接下去說明。
  • 現在分詞片語作後置修飾 (Present Participle Phrase as Postmodifier)
    The hackers triggered scheduled commands, prompting the system to resend procurement notices to contractors, it said.
    句尾的「prompting the system to...」是由現在分詞帶領的分詞片語，用來補充說明前面主句所引發的結果（主動語態），相當於 and prompted the system...。
  • 過去分詞片語作後置修飾 (Past Participle Phrase as Postmodifier)
    ...a concealed scheduling-management interface created by the system vendor had been breached by someone using an overseas IP address.
    句中的「created by the system vendor」是過去分詞片語，用來修飾前面的名詞 interface（介面），表被動與完成的概念，等於一個省略了位置代名詞與be動詞的形容詞子句（which was created by...）。
  • 被動語態 (Passive Voice)
    However, CSIST yesterday said that the developer of its procurement system had hidden the system’s task-management interface, which was breached via an overseas IP address.
    句中的「was breached」使用了「be + 過去分詞」的被動語態結構，強調介面是「被」來自海外的IP位址所入侵，受詞成為被敘述的對象。
